[#changelog-draft-generation-1]
== Draft Generation 1 — current

The `ALV1`, `ALA1`, and current container documents are *unfrozen normative drafts* for the reference POC. They define the current conformance target, not a permanent compatibility promise. Breaking changes are permitted during `0.x` development when they are intentional, documented, and accompanied by updated conformance vectors and implementations.

Encoder heuristics are non-normative. Search strategies, presets, rate control, scene-cut policy, and other encoder decisions may change without a format-generation change as long as emitted streams conform to the current draft.

* Removed obsolete entropy mode 1. Draft Generation 1 accepts only raw mode 0 and canonical-uvarint static-rANS mode 2; canonical and independent decoders reject every other mode.
