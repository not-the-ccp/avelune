The normative draft documents in this directory define current decoded behavior. They are the source of truth when they disagree with an implementation. The project is still `0.x`, so syntax, identifiers, constraints, and decoded semantics may change incompatibly when evidence supports a better design.

`ALV1` and `ALA1` mean *Draft Generation 1*. They do not mean the format has reached stable 1.0.

[#spec-current-normative-draft]
== Reading order

. Start with the xref:001-v1-baseline-profile.adoc#baseline-video[Baseline profile] to understand the interoperability boundary.
. Read xref:common/001-entropy-v1.adoc#entropy-canonical-unsigned-varint[common integer and entropy coding], which is shared by both media codecs.
. Use the xref:video/001-video-v1.adoc#alv1-frame-packet[ALV1 video] and xref:audio/001-audio-v1.adoc#ala1-packet[ALA1 audio] documents for decoded media semantics.
. Use the xref:container/001-container-v1.adoc#avl-fixed-file-header[AVL container] document for stream descriptors, packets, epochs, and byte-range access.
. Finish with the xref:conformance/001-v1.adoc#conformance-general[conformance requirements] when implementing or validating a decoder.

[#spec-normative-language]
== Normative language and conventions

The key words *MUST*, *MUST NOT*, *SHOULD*, *SHOULD NOT*, and *MAY* express requirement strength.
All byte offsets and ranges are zero-based. Half-open ranges use `[start,end)` notation. Fixed-width
integers are little-endian unless a structure explicitly says otherwise. Mathematical `floor`,
division, and modulo behavior is stated explicitly where host-language integer behavior could differ.

The specification defines accepted syntax and decoded results. Encoder search, rate control, preset
behavior, and other choices that do not affect conformance are non-normative unless explicitly stated.

[#spec-document-status]
== Document status

Files prefixed `000-` are historical experiments and are non-normative.

[#spec-change-discipline]
== Change discipline

A format change is complete only when the normative draft, affected implementations, conformance vectors/tests, public docs, and `spec/CHANGELOG.adoc` agree. During the unstable phase, do not retain an inferior design solely to decode an earlier development artifact.

See xref:../docs/development/VERSIONING.adoc[../docs/development/VERSIONING.adoc].
